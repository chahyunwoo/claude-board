# claude-board

여러 프로젝트에 흩어진 Claude Code 세션을 한 화면에서 보는 로컬 대시보드.

- **어느 세션이 내 답을 기다리는가**
- **어느 세션이 멈춰 있는가**
- **컨텍스트가 얼마나 찼는가** — 새 세션을 열 시점 판단

## 원칙

데이터는 이 기계를 떠나지 않는다. 중앙 서버 없음, 계정 없음, 외부 전송 없음.
백엔드는 `127.0.0.1` 에만 바인딩한다.
