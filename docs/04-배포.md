# 04. 배포

## 1차 — 로컬 실행

개인 도구이므로 배포보다 실행 편의가 우선이다.

```bash
./gradlew bootRun            # 개발
./gradlew bootJar            # 산출물
java -jar build/libs/claude-board.jar
```

전제: **JDK 21**. `brew install openjdk@21`

편의를 위한 셸 래퍼:
```bash
#!/bin/sh
# ~/.local/bin/claude-board
exec /opt/homebrew/opt/openjdk@21/bin/java \
  -jar "$HOME/Documents/projects/hyunwoo/claude-board/build/libs/claude-board.jar" "$@"
```

## 상시 실행 (선택)

LaunchAgent 로 등록한다.

```xml
<key>Label</key><string>local.claude-board</string>
<key>ProgramArguments</key>
<array>
  <string>/opt/homebrew/opt/openjdk@21/bin/java</string>
  <string>-jar</string>
  <string>/절대경로/claude-board.jar</string>
</array>
<key>RunAtLoad</key><true/>
<key>KeepAlive</key><true/>
```

주의 — 실측으로 확인된 함정:
`launchctl bootstrap` 만으로는 시작되지 않는 경우가 있다 (`runs = 0`).

```bash
launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/local.claude-board.plist
launchctl print "gui/$(id -u)/local.claude-board" | grep -E "state|runs"
# state = not running / runs = 0 이면
launchctl kickstart -k "gui/$(id -u)/local.claude-board"
```

## 2차 — 남에게 배포한다면

JVM 설치를 요구하는 게 가장 큰 마찰이다. 그때 검토할 것:

**GraalVM native-image**
```bash
./gradlew nativeCompile      # 단일 네이티브 바이너리
```
- JDK 설치 불필요, 기동 수십 ms
- 대신 빌드 파이프라인이 복잡해지고, 리플렉션 힌트를 잡아줘야 한다
- Spring Boot 3 는 AOT 지원이 있어 예전보다 수월하다

지금 하지 않는다. 로컬에서 쓸 만하다고 확인된 뒤에.

## 다기기 — 1차 범위 밖

프로·에어·맥미니에 세션이 흩어져 있다면 **중앙 서버 없이** Tailscale 로 묶을 수 있다.

```
[대시보드] ──tailnet──> 다른 기계 :7777/api/sessions
```

구현 시 주의:
- 원격용 바인딩은 `127.0.0.1` 이 아니라 **tailnet 주소로만**. `0.0.0.0` 금지
- 원격 응답은 신뢰 경계 밖. 스키마 검증 후 사용

## 배포 전 점검

- [ ] `127.0.0.1` 외 바인딩이 없는지 (`lsof -nP -iTCP -sTCP:LISTEN`)
- [ ] jar 에 세션 데이터나 로그가 섞이지 않았는지
- [ ] `.env`·토큰류가 저장소에 없는지 (`gitleaks dir .`)
- [ ] README 에 "데이터가 기계를 떠나지 않는다"를 명시했는지
