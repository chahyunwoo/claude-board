# 04. 배포

## 형태

npm 전역 패키지 하나. 백엔드가 프론트 빌드 결과를 정적 서빙하므로
설치물이 하나로 끝난다.

```bash
npm i -g claude-board
claude-board
```

`package.json`:
```jsonc
{
  "name": "claude-board",
  "bin": { "claude-board": "./dist/cli.js" },
  "files": ["dist"],
  "engines": { "node": ">=20" }
}
```

빌드는 `web/` 을 먼저 만들고 `dist/public/` 으로 복사한 뒤 서버를 번들한다.

## 상시 실행 (선택)

항상 켜두고 싶으면 LaunchAgent 로 등록한다.
화면보호기 서버에서 검증된 방식과 동일하다.

```xml
<key>Label</key><string>local.claude-board</string>
<key>ProgramArguments</key>
<array>
  <string>/opt/homebrew/bin/claude-board</string>
  <string>--no-open</string>
</array>
<key>RunAtLoad</key><true/>
<key>KeepAlive</key><true/>
```

주의 — 실측으로 확인된 함정:
`launchctl bootstrap` 만으로는 시작되지 않는 경우가 있다 (`runs = 0`).
등록 후 반드시 확인하고, 필요하면 `kickstart` 한다.

```bash
launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/local.claude-board.plist
launchctl print "gui/$(id -u)/local.claude-board" | grep -E "state|runs"
# state = not running / runs = 0 이면
launchctl kickstart -k "gui/$(id -u)/local.claude-board"
```

## 다기기 — 1차 범위 밖

프로·에어·맥미니에 세션이 흩어져 있다면, **중앙 서버 없이** Tailscale 로 묶을 수 있다.

```
[프로 대시보드] ──tailnet──> 에어   :7777/api/sessions
                └─tailnet──> 맥미니 :7777/api/sessions
```

각 기계가 자기 수집기를 띄우고, 대시보드가 tailnet 으로 직접 가져온다.
데이터는 각자 기계에 남는다.

구현 시 주의:
- 원격용 바인딩은 `127.0.0.1` 이 아니라 **tailnet 주소로만** 열 것. `0.0.0.0` 금지
- 원격 응답은 신뢰 경계 밖이다. 스키마 검증 후 사용
- 1차에서는 만들지 않는다. 로컬이 쓸 만하다고 확인된 뒤에

## 배포 전 점검

- [ ] `127.0.0.1` 외 바인딩이 없는지 (`lsof -nP -iTCP -sTCP:LISTEN`)
- [ ] 패키지에 세션 데이터나 로그가 섞여 들어가지 않는지 (`npm pack` 후 내용 확인)
- [ ] `.env`·토큰류가 저장소에 없는지 (`gitleaks dir .`)
- [ ] README 에 "데이터가 기계를 떠나지 않는다"를 명시했는지
