# 03. 프론트

## 스택

| | 선택 | 이유 |
|---|---|---|
| 프레임워크 | React + Vite | 기존 스택과 동일 |
| 상태 | TanStack Query (SSE 구독) | |
| 스타일 | CSS Modules 또는 Tailwind | 취향. 규모가 작아 어느 쪽도 무방 |
| 린터 | Biome | 백엔드와 동일 |

빌드 결과를 백엔드가 정적 서빙한다 (`02-백엔드.md` 참고).
FSD 는 적용하지 않는다 — 화면이 하나뿐이라 레이어가 오히려 부담이다.

### 한 줄에 담기는 것

```
프로젝트명   브랜치   제목
  경과시간 · ctx 토큰 · N번째 세션
  ↳ 마지막 프롬프트 (1줄, 넘치면 말줄임)
```

**마지막 프롬프트를 넣는 이유**: 제목만으로는 "내가 뭘 시켰더라"가 안 떠오른다.
마지막 발화를 보면 맥락이 즉시 복구된다.

### 정렬

```
답변 대기 → 멈춤 의심 → 작업 중 → 유휴
```
각 그룹 안에서는 **오래된 순**. 방치된 것이 위로 올라온다.

`ended` 는 기본 숨김. 토글로 표시.

## 상호작용

최소한만 둔다. 조회 전용 원칙([00-개요](00-개요.md))을 지킨다.

| 동작 | 결과 |
|---|---|
| 프로젝트 줄 클릭 | 같은 프로젝트의 다른 세션 펼치기/접기 |
| 경로 클릭 | 클립보드에 `cwd` 복사 |
| `ended` 토글 | 종료된 세션 표시/숨김 |
| 새로고침 | SSE 가 5초마다 하므로 버튼은 불필요 |

세션 종료·재개 버튼은 **넣지 않는다.**

## 시각 규칙

상태를 **색이 아니라 위치와 라벨로** 먼저 구분한다. 색은 보조.

| 상태 | 색 |
|---|---|
| 답변 대기 | 앰버 — 시선을 끌어야 함 |
| 멈춤 의심 | 레드 |
| 작업 중 | 그린 |
| 유휴 | 회색 |

컨텍스트 토큰은 절대값으로 표기 (`458K`).
상한 대비 %는 [00-개요](00-개요.md) 미결 3번이 정해진 뒤에.

## 표시하지 않는 것

- 대화 내용 전문
- 토큰 비용·요금
- 파일 변경 이력

## 상시 표시를 고려한 처리

Studio Display 한쪽에 띄워둘 가능성이 있다. 그 경우:

- 배경은 어둡게, 전체 휘도를 낮게
- 갱신 시 레이아웃이 튀지 않게 (높이 고정, 내용만 교체)
- 깜빡이는 애니메이션 금지

OLED 에 띄울 계획이면 정지 화면이 되지 않도록 추가 검토가 필요하다.
1차 범위 밖.
