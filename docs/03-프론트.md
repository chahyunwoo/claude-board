# 03. 프론트

## 스택

| | 선택 | 이유 |
|---|---|---|
| 프레임워크 | **Vue 3 + Vite** | 화면이 하나라 규모가 맞다. 기존 React 스택에 더해 폭을 넓힌다 |
| 언어 | TypeScript | |
| 상태 | Pinia (필요해지면) | 화면 하나라 없어도 될 수 있다 |
| 스타일 | CSS (scoped) | SFC 의 scoped 스타일로 충분 |

Composition API + `<script setup>` 을 쓴다.
빌드 결과는 `src/main/resources/static/` 으로 복사되어 Spring 이 서빙한다
([02-백엔드](02-백엔드.md) 참고).

FSD 는 적용하지 않는다 — 화면이 하나뿐이라 레이어가 오히려 부담이다.

### SSE 구독

서버는 `event: snapshot` 으로 보내므로 **`onmessage` 가 아니라
`addEventListener('snapshot', …)`** 을 쓴다 (`onmessage` 는 이름 없는 이벤트만 받는다).

```ts
const es = new EventSource('/api/stream')
es.addEventListener('snapshot', (e) => { board.value = JSON.parse(e.data) })
es.onerror = () => { /* 재연결은 브라우저가 자동 */ }
```

**중복 렌더는 서버 쪽에서 이미 막아뒀다** ([02-백엔드](02-백엔드.md)) —
과거 이벤트를 재생하지 않고 이벤트 id 도 쓰지 않으므로 브라우저가
`Last-Event-ID` 로 재생을 요구하지 않는다. 스냅샷은 누적이 아니라 매번 전체 상태라
같은 것을 두 번 받아도 같은 상태로 수렴한다. **클라이언트는 통째로 교체하면 된다.**

15초마다 오는 주석 프레임(`:`)은 끊김 감지용이고 이벤트가 아니라 무시된다.

TanStack Query 는 쓰지 않는다. SSE 한 줄이면 되는데 캐시 계층이 불필요하다.

### 개발 중 API 연결

백엔드는 `127.0.0.1:7777` 에만 바인딩한다. Vite dev 서버는 포트가 다르므로
**프록시를 설정한다** — CORS 를 여는 것이 아니다
(여는 순간 "데이터는 기계를 떠나지 않는다"의 경계가 흐려진다).

```ts
// vite.config.ts
server: { proxy: { '/api': 'http://127.0.0.1:7777' } }
```

### 한 줄에 담기는 것

```
프로젝트명   브랜치   제목
  경과시간 · ctx 토큰 · N번째 세션
  ↳ 마지막 프롬프트 (1줄, 넘치면 말줄임)
```

**마지막 프롬프트를 넣는 이유**: 제목만으로는 "내가 뭘 시켰더라"가 안 떠오른다.
마지막 발화를 보면 맥락이 즉시 복구된다.

### 정렬

```
답변 대기 → 멈춤 의심 → 작업 중 → 유휴
```
각 그룹 안에서는 **오래된 순**. 방치된 것이 위로 올라온다.

`ended` 는 기본 숨김. 토글로 표시.

## 상호작용

최소한만 둔다. 조회 전용 원칙([00-개요](00-개요.md))을 지킨다.

| 동작 | 결과 |
|---|---|
| 프로젝트 줄 클릭 | 같은 프로젝트의 다른 세션 펼치기/접기 |
| 경로 클릭 | 클립보드에 `cwd` 복사 |
| `ended` 토글 | 종료된 세션 표시/숨김 |
| 새로고침 | SSE 가 5초마다 하므로 버튼은 불필요 |

세션 종료·재개 버튼은 **넣지 않는다.**

## 시각 규칙

상태를 **색이 아니라 위치와 라벨로** 먼저 구분한다. 색은 보조.

| 상태 | 색 |
|---|---|
| 답변 대기 | 앰버 — 시선을 끌어야 함 |
| 멈춤 의심 | 레드 |
| 작업 중 | 그린 |
| 유휴 | 회색 |

컨텍스트 토큰은 **절대값 · 상한 · % 셋을 모두** 낸다
([00-개요](00-개요.md) 결정사항 3). 기록의 모델명이 `claude-opus-5` 로만 남아
`[1m]` 변형이 구분되지 않아 **분모가 틀릴 수 있다** — 그래도 절대값으로는 판단이 된다.
API 가 `contextTokens` · `contextLimit` · `contextRatio` 를 모두 준다.

## 표시하지 않는 것

- 대화 내용 전문
- 토큰 비용·요금
- 파일 변경 이력

## 상시 표시를 고려한 처리

Studio Display 한쪽에 띄워둘 가능성이 있다. 그 경우:

- 배경은 어둡게, 전체 휘도를 낮게
- 갱신 시 레이아웃이 튀지 않게 (높이 고정, 내용만 교체)
- 깜빡이는 애니메이션 금지

OLED 에 띄울 계획이면 정지 화면이 되지 않도록 추가 검토가 필요하다.
1차 범위 밖.
